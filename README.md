# nuricelab-spack-recipes

Spack package recipes for nuRiceLab software.

- `laropticks` — LArSoft GPU optical-photon module (source: nuRiceLab/laropticks)
- `RiceOpticks`    — RiceOpticks GPU optical simulation (source: nuRiceLab/RiceOpticks)

Add to a Spack instance with:

    spack repo add nuricelab-spack-recipes
